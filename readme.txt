== Installation ==

= Installing the Plugin =

1. In WordPress admin, go to **Plugins → Add New**.
2. Click **Upload Plugin** and select the AEO God Mode zip file.
3. Click **Install Now**, then **Activate**.

Or upload the `aeo-god-mode` folder to `/wp-content/plugins/` via FTP and activate it from the **Plugins** screen.


= First-Run Setup =

Activation auto-redirects you to the 5-step Setup Wizard. Missed the redirect? Click **AEO** in the WordPress admin sidebar, then **Setup Wizard**.

The wizard walks you through:

1. **Welcome**. Quick overview of what AEO God Mode does.
2. **Detect Plugins**. Scans for Yoast SEO, Rank Math, SEOPress, All in One SEO. Imports your existing settings if found.
3. **Business Info**. Site name, URL, business type, location (used for schema). Pre-filled from WordPress settings where possible.
4. **Features**. Choose which AEO modules to enable. All free modules on by default.
5. **Complete**. Initial content scan and your starting AEO health score.

Setup takes under 5 minutes on most sites.

AEO means structuring your content so AI answer engines (ChatGPT, Perplexity, Claude, Google AI Overviews, Gemini) can find it, understand it, and cite it. Also called GEO (Generative Engine Optimization), AIO (AI Optimization), LLM SEO, AI SEO, GAIO. Same shift, different acronyms. From optimising for search result links to optimising for AI-generated answers.

No. Schema and metadata generated server-side as lightweight JSON-LD. The AI crawler log fires a single database write only when a recognised AI bot is detected. Frontend overhead is a few meta tags and HTTP headers, measured in microseconds.


= Will it conflict with my existing schema markup? =

No. The Conflict Detector scans for existing schema output from Yoast, Rank Math, SEOPress, and All in One SEO before adding any markup. Where a conflict appears, it defers to your existing plugin. You can also manually choose which schema types AEO God Mode handles.


= Will this help me rank in Google AI Overviews and ChatGPT Search? =

Yes, that's the whole point. AEO God Mode generates the structured signals (schema, llms.txt, E-E-A-T markup, answer-shaped content) that AI engines use to identify and cite trustworthy sources. We can't guarantee placement (no plugin can), but we give you every signal those engines look for.

The free version requires no account. AI Metadata Generation (free tier) uses included credits. Pro features need a license key from https://aeogodmode.io. No data leaves your site beyond what you authorise.


= Is this white-hat SEO? =

Yes. AEO God Mode produces standards-compliant schema, llms.txt, robots.txt directives, and metadata. Nothing cloaked, no doorway pages, no manipulation. Just the structured signals AI engines and Google's guidelines explicitly recommend.

== External Services ==

This plugin connects to external services in the following ways:

**License Validation (Pro)**
Requests sent to aeogodmode.io to validate Pro license keys and check for Pro plugin updates. Only the license key and site URL are transmitted. No personal data sent.

**AI Content Generation & Analysis**
When you manually start an AI generation task (like creating AI Metadata), the plugin securely sends the post content (title and body text) to aeogodmode.io/wp-json/asgm/v1/ai-assist for processing. Free users get 5 credits per month (no rollover). Pro users unlock unlimited analysis features like FAQ extraction and advanced schema generation. Only activates when you explicitly click the 'Generate' button on a post.

**Citation Tracking (Pro)**
The Citation Tracker queries the Perplexity, OpenAI (ChatGPT), Google (Gemini), and Anthropic (Claude) APIs to check whether your domain appears in AI-generated responses. Requires explicit opt-in. Only activates after a valid Pro license is entered. API keys stored encrypted in the WordPress database with AES-256 using your WordPress salts. Never shared with any third party.

**Google Search Console (Pro)**
The GSC integration routes OAuth token exchanges through a proxy at aeogodmode.io to securely connect your Google Search Console account. Only OAuth tokens and GSC API requests are proxied. No site content transmitted through this proxy.
