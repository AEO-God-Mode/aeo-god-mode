# Code of Conduct

The AEO God Mode project adopts the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct.

The full text is available at the link above. By participating in this project (filing issues, opening pull requests, joining discussions, contributing translations) you agree to abide by its terms.

## In short

Treat everyone with respect. Disagree on the work, not the person. Help newcomers. If a behaviour makes you or someone else uncomfortable, please report it.

## Reporting

If you experience or witness behaviour that violates the Contributor Covenant, please report it privately by emailing **security@aeogodmode.io**. Reports are read by the project maintainer only and are not shared further without your consent.

Public issues, comments, and PRs are not the place for these reports.

## Enforcement

The maintainer follows the Contributor Covenant Enforcement Guidelines: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

Outcomes range from a private warning, through temporary interaction limits, up to a permanent ban depending on severity.
